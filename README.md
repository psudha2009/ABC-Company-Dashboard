# ABC Executive Summary Dashboard (Excel)

## Project Overview

This project is an Executive Summary Dashboard created using Microsoft Excel to analyze sales performance across product categories, countries, regions, and sales channels.

## Dashboard Features

### KPI Cards
- Total Revenue: $198,505
- Total Gross Profit: $84,949.23
- Gross Profit Margin: 42.79%
- Total Units Sold: 1,270
- Total Orders: 487
- COGS: $113,556

### Visualizations
- Revenue and Profit by Month (Line Chart)
- Top 5 Countries by Revenue (Bar Chart)
- Revenue Share by Channel (Pie Chart)
- Region-wise Comparison (Doughnut Chart)
- Country-wise Revenue Map

### Interactive Elements
- Product Category Slicer
- Country Slicer
- Quarter Slicer

## Excel Features Used

- Pivot Tables

- Map Charts
- Calculated Fields

- Dashboard Design & Formatting
